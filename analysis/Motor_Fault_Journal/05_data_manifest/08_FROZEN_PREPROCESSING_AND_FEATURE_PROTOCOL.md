# Frozen Preprocessing and Feature Protocol

**Status:** Frozen before the final benchmark rerun  
**Date frozen:** 24 August 2026  
**Machine-readable feature sets:** `frozen_feature_sets.json`  
**Feature-quality audit:** `feature_table_audit.json`

## 1. Input and units

The input is the recoverable single-phase current channel stored in ADC-like numeric values. A defensible end-to-end calibration equation converting every sample to amperes is not available; therefore:

- waveform-amplitude features are reported in ADC units;
- energy features are reported in squared ADC-related units;
- spectral band powers are reported in squared FFT-magnitude units;
- no manuscript table or axis may label these quantities as amperes or ampere-squared.

All primary windows contain 650 samples acquired at a nominal 650 Hz, providing one second of current data.

## 2. Window-level preprocessing

For each window with samples `x[n]`, `n = 0,...,649`:

1. Convert recoverable numeric values to double precision.
2. Calculate the window arithmetic mean.
3. Centre the window: `xc[n] = x[n] - mean(x)`.
4. Apply no time-domain filtering and no resampling.
5. Use `xc` for every frozen time-domain feature.
6. Multiply `xc` by a symmetric Hann taper generated by `numpy.hanning(650)` before the FFT.
7. Compute the real FFT and squared magnitude spectrum.

No whole-record normalization occurs before data partitioning.

## 3. Spectrum definition

- FFT length: 650.
- Frequency range: 0 to 325 Hz.
- Bin spacing: 1 Hz.
- Power representation: `P[k] = |RFFT(xc * Hann)[k]|^2`.
- The power spectrum is not amplitude-normalized. Equal primary window length makes values internally comparable across the frozen benchmark.
- Frequency bands use a closed lower and open upper bound, except the final band includes the Nyquist bin through a numerical upper allowance.

The feature set summarizes broad spectral distributions. It does not claim exact broken-bar sideband tracking because synchronized RPM/slip is unavailable.

## 4. Frozen time-domain features

| Feature | Definition | Unit/interpretation |
|---|---|---|
| `std` | Sample standard deviation of `xc`, with `ddof=1` | ADC units |
| `rms` | Square root of mean `xc^2` | ADC units |
| `peak_abs` | Maximum absolute centred amplitude | ADC units |
| `peak_to_peak` | Maximum `xc` minus minimum `xc` | ADC units |
| `skewness` | Bias-corrected sample skewness | Dimensionless |
| `kurtosis` | Bias-corrected Fisher excess kurtosis | Dimensionless |
| `crest_factor` | `peak_abs / rms` | Dimensionless |
| `shape_factor` | `rms / mean(abs(xc))` | Dimensionless |
| `impulse_factor` | `peak_abs / mean(abs(xc))` | Dimensionless |
| `clearance_factor` | `peak_abs / mean(sqrt(abs(xc)))^2` | Dimensionless ratio |
| `median_abs_deviation` | Median absolute deviation, scale factor 1 | ADC units |
| `interquartile_range` | 75th percentile minus 25th percentile | ADC units |
| `energy` | Mean `xc^2` | ADC-squared; equals RMS squared |

These 13 features form the frozen **time-domain** set.

## 6. Combined and excluded features

The frozen **combined** set contains the 13 time features followed by the 10 frequency features, for 23 predictors total.

`mean_centered` is excluded from every final model. By construction, its theoretical value is zero. Its observed range of approximately -5.67e-14 to +5.67e-14 is floating-point residue and has no physical diagnostic meaning.

Although `std` and `rms`, and `energy` and `rms`, are strongly or deterministically related, they are retained because they are conventional diagnostic descriptors and support comparison with prior feature-based studies. Their individual importance must not be interpreted as independent causal evidence.

## 7. Model-pipeline preprocessing

- Missing-value imputation, if required, uses the training-set median only.
- Standardization, where required by the classifier, uses training-set mean and standard deviation only.
- Validation and test data are transformed using parameters fitted on training data.
- Tree-based models may use unscaled features but must use the same frozen columns.
- Any feature selection must be fitted inside the training procedure and is not part of the default 23-feature benchmark.
- Resampling or class balancing, if used, applies to training data only.

The present frozen table contains no missing or infinite values, so imputation is a defensive pipeline component rather than an active transformation.

## 9. Prohibited features and interpretations

Without additional verified metadata, the final model must not use:

- exact slip-dependent BRB sideband amplitudes;
- order-tracked features requiring synchronized RPM;
- vibration features labelled as F1/F2/F3;
- temperature features;
- current features labelled in amperes;
- features computed using information from validation or test subsets.
